# 波動與光學 SUPER 複習系統

選修物理第一至四章（波動、聲波、幾何光學、物理光學）的純前端複習網站：把四章拆成 21 個知識節點，每個節點都有核心公式卡、解題特徵引導、常見陷阱、跨章連結、大考題型解析，並搭配可調參數的互動實驗、Manim 動畫講解與分級題庫。

## 線上使用

網站不需註冊或安裝任何套件，用桌機或手機的現代瀏覽器開啟即可。開啟 `index.html` 會自動轉往主頁面 `wave_optics_review.html`。

## 貫穿四章的主軸

本站的內容編排圍繞三句話：

1. **波速由介質決定、頻率由波源決定**，波長是兩者相除的結果。從繩波 $v=\sqrt{F/\mu}$ 到光的 $v=c/n$ 都適用。
2. **穿越界面時頻率永遠不變**，改變的是波速與波長，而且兩者同增同減。
3. **干涉的判準只有一條**：波程差為 $n\lambda$ 是完全建設性干涉、為 $(m-\frac{1}{2})\lambda$ 是完全破壞性干涉。水波的腹線／節線與光的亮紋／暗紋是同一件事。

若瀏覽器限制本機檔案載入，且電腦已安裝 Python 3，可在專案目錄執行：

接著前往 `http://localhost:8000/`。數學公式使用 CDN 版 MathJax、字型使用 Google Fonts，完整呈現這兩項外部資源需要網路連線（瀏覽器已有快取時除外）。

## 開發者：改完動畫請跑自我檢查

Canvas 與 SVG 就算把像素畫在錯誤的座標、或讓兩段文字疊在一起，瀏覽器
控制台也不會報錯。因此本專案附了一支自動化視覺健檢：

```bash
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000/wave_optics_review.html?selftest=1`。

它會把 34 個實驗模式 × 3 種畫布寬度全部跑一遍，攔截每一次 `fillText`
記錄文字的實際外框，檢查三件事：執行期錯誤、畫布文字互相重疊、文字被
畫到畫布外。報告直接顯示在頁面上。

改完任何 `draw` 函式後請跑一次再宣告完成——這正是 `.agents/rules/`
守則第 1 條與第 4 條要求的驗證步驟。

## 內容來源與試題授權說明

動畫講解由本專案自行以 Manim Community 產生（純 Python，無外部素材），角色「彈彈 Tan」與「答答 Da」為原創。繩波反射的力學模型以 Howard Georgi《The Physics of Waves》第 6 章與 David Morin《Transverse waves on a string》核對。

網站的知識節點劃分、公式整理、解題特徵引導、對照表與題庫，皆為依據高中選修物理課程範圍重新編寫的複習教材。近 5 年（109–113 學年度）分科測驗與指考波動光學真題均直接對接財團法人大學入學考試中心（大考中心 CEEC）官方公開試卷 PDF，以 300 DPI 超高解析度精確裁切原始題目與圖表，提供最具考場臨場感的全真練習體驗；每個選項皆附「為什麼對／為什麼是誘答」深入解析。
