# 波動與光學 SUPER 複習系統

選修物理第一至四章（波動、聲波、幾何光學、物理光學）的純前端複習網站：把四章拆成 20 個知識節點，每個節點都有核心公式卡、解題特徵引導、常見陷阱、跨章連結、大考題型解析，並搭配可調參數的互動實驗與分級題庫。

## 線上使用

網站不需註冊或安裝任何套件，用桌機或手機的現代瀏覽器開啟即可。開啟 `index.html` 會自動轉往主頁面 `wave_optics_review.html`。

### 節點頁的四層結構

每個節點頁依「先看得懂 → 再算得出 → 最後認得出題型」的順序排列：

1. **核心公式與觀念**：公式卡附一句話重點（anchor）與詳細說明，部分公式卡帶有即時檢核小測。
2. **解題特徵引導**：題目特徵 → 解題橋樑 → 常見陷阱，三段式對照。
3. **大考與段考題型**：歷屆學測、指考題型解析，標有官方公布的答對率。
4. **互動實驗入口與題庫入口**：一鍵跳到對應的模擬與該節點的題目。

每個實驗下方都有**時間軸**：可以拖曳到任意時刻，或用 ⏴ ⏵ 逐格前進後退，適合慢慢比對疊加、反射等過程（拖曳時會自動暫停）。互動實驗也支援 `#lab-<id>:<mode>` 深層連結，可直接分享某一個模式。

所有動畫共用 `assets/js/wave-runtime.js` 的固定步長時鐘，因此在不同更新率的螢幕上速度一致；離開頁面時會自動停止 `requestAnimationFrame` 並移除事件監聽器。若作業系統設定為「減少動態效果」，實驗載入時會自動暫停。

## 貫穿四章的主軸

本站的內容編排圍繞三句話：

1. **波速由介質決定、頻率由波源決定**，波長是兩者相除的結果。從繩波 $v=\sqrt{F/\mu}$ 到光的 $v=c/n$ 都適用。
2. **穿越界面時頻率永遠不變**，改變的是波速與波長，而且兩者同增同減。
3. **干涉的判準只有一條**：波程差為 $n\lambda$ 是完全建設性干涉、為 $(m-\frac{1}{2})\lambda$ 是完全破壞性干涉。水波的腹線／節線與光的亮紋／暗紋是同一件事。

## 本機使用

本專案是純 HTML、CSS 與 JavaScript，不需編譯或安裝前端套件。

### 直接開啟

下載後直接開啟 `index.html` 即可。

### 使用本機伺服器

若瀏覽器限制本機檔案載入，且電腦已安裝 Python 3，可在專案目錄執行：

```bash
python3 -m http.server 8000
```

接著前往 `http://localhost:8000/`。數學公式使用 CDN 版 MathJax、字型使用 Google Fonts，完整呈現這兩項外部資源需要網路連線（瀏覽器已有快取時除外）。

## 專案結構

```text
physenior/
├─ index.html                   # 入口，自動轉往主頁面
├─ wave_optics_review.html      # 主要介面、路由、14 個互動實驗

│  ├─ modulesData.js            # 四個模組的教材內容、概念圖、題型解析
│  └─ questionBank.js           # N01–N20 分級題庫（80 題）

│  ├─ css/interaction-runtime.css   # 互動元件樣式
│  └─ js/wave-runtime.js            # 固定步長時鐘與檢視生命週期清理

```

修改 `data/` 內的資料檔後重新整理瀏覽器即可看到結果，不需編譯或打包。
