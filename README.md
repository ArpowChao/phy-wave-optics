# 波動與光學・學習筆記

給台灣高三剛開始學習選修物理 III 的純前端教材。以「觀察現象 → 理解關係 → 做一題檢核」為主線，涵蓋波動、聲波、幾何光學與物理光學。

## 使用

開啟 `index.html`，或在專案資料夾啟動本機伺服器：

```bash
python -m http.server 8000
```

瀏覽 `http://localhost:8000/`。不需建置或註冊；MathJax 與字型由 CDN 載入，完整數學排版需要網路。

## 學習方式

- 首頁可從第一節開始，或依課堂進度選章節；側欄只展開目前章節。
- 20 節核心教材各有目標、先備連結、觀察問題、短例題與附理由的檢核。N21 都卜勒效應為延伸選讀。
- 核心關係先呈現；公式適用條件、動畫、解題提醒、大考題型與跨章延伸按需展開。
- 導讀會開啟相應實驗模式。水波干涉直接進入含 2D／3D／1D 的完整實驗；`water_interference.html` 也提供自由操作與可選的三步導讀。
- 98 題題庫以主題、難度與來源篩選，每頁最多 5 題；「記憶 → 理解 → 應用 → 分析」逐步練習。
- 自行確認理解與錯題紀錄只保存在目前瀏覽器。看過頁面不會自動算作理解；已確認的節點可以取消。
- 公式、動畫與大考題型可依章節查找；對照表一次展開一個主題。

16 個互動實驗保留原有調參、時間軸、逐格播放及 0.1×–1.5× 速度控制；3D 多元件光學工作臺列為延伸。小振幅橫波實驗固定介質波速時，調整頻率會同步改變波長。諧音疊加也處理缺少基音或全部振幅為零的情形。

水波圖保留 d 尺寸線與 λ 比例尺，可切換 λ／cm／兩者／隱藏，並操作亮暗紋、腹節線、相位、衰減與隨機出題。P 的量測使用模型座標，改變視窗大小時仍維持相同路徑讀數。獨立水波頁另可切換「瞬間位移」與「振幅分布」，避免把某瞬間水面為零誤判成節線。完全相消必須考慮相位與抵達振幅是否相同。

主頁水波操作分為「波源間距與長度顯示」及「水波與圖示」兩張卡片，手機改為單欄。必要腳本載入失敗或頁面渲染中斷時，會顯示重載按鈕與獨立水波頁入口。

共振頁 N12 收錄玻璃杯、慢動作杯壁、建築震動、節拍器同步與塔可馬吊橋五段影片，以觀察問題和判讀區分受迫共振、耦合同步與自激顫振。保留共鳴空氣柱實驗與例題，另附三題檢核及來源。影片展開時才載入，收合後移除播放器；也可直接開啟 YouTube 原始連結。

N12 的盪鞦韆動畫提供「正弦波做功對照」與「受迫鞦韆」兩種視角。可調推力頻率比、相位、推力與阻尼，暫停、逐步或拖曳時間；同步看推力 F、速度 v、功率 Fv 及累積做功。固定波形不把累積功當作振幅；受迫小角度模型以 RK4 同時計算運動、外力功與耗散，驗證 E − E₀ = W − D。

N13–N15 的司乃耳實驗分為「單一光線」「水下光扇」「斯涅爾窗（水下仰望）」三種模式。單一光線依非偏振光的菲涅耳公式顯示反射率 R，可看到 R 在臨界角處連續升到 100%。水下光扇對應水槽光扇實驗，標出出光圓 r = h·tanθc。斯涅爾窗左側為側視光路，右側以逐像素光線追蹤算出魚眼仰望影像，可切換泳池／深海與水面波動；畫布下方附真實照片對照，按「套用到模擬」即可把參數調成接近照片的情況。

N15 另有光纖實驗，分為「階射率光纖（多模）」「彎曲光纖」「漸變折射率光纖」「單模光纖」「三種比較與優劣」五種模式。所有光線為單一波長、畫成同一顏色。階射率模式追蹤芯層／包層界面的子午光線：超過接受角（NA = √(n₁² − n₂²)）的光依菲涅耳反射率逐次漏進包層；光點依光程時間前進，輸入、輸出脈衝圖顯示模態色散 Δt ≈ (L·n₁/c)(n₁/n₂ − 1)。彎曲模式可拖曳畫布或用滑桿改變彎曲角度（0–180°）與半徑（4–28 倍芯半徑），比例尺固定，讀數比較同一組光在直光纖與彎曲後到達出口的光量，並列出沿中心光線不漏光所需的 R ≥ a·n₂/(n₁ − n₂)。漸變折射率模式以 RK4 積分拋物線分布中的光線；單模模式為示意。「射入的光」可選一束光（多條）或一條光線（自己調入射角，圖上標出打到界面的入射角並與臨界角比較；彎曲模式標出彎曲處最小的入射角）。預設組合可切換「誇大以便觀察（1.50／1.40）」與「接近真實（1.48／1.46）」。實驗下方整理光纖和銅線的優缺點與三種光纖比較表；題庫附 N15-FIBER-1～3。光纖各模式在光纖旁附折射率分布圖 n(r)（階射率、漸變、單模；窄螢幕放在光纖下方）。

N15 另有「半圓柱玻璃」實驗：平行光由平面射入，圓弧面上的入射角 sin θ = h/R，高於臨界高度 R/n 的光全反射；分「一條光線（拖曳或滑桿調整入射高度，標出法線、入射角與 h、R）」「五條平行光甲～戊（可個別拖曳高度）」「整片平行光（看球面像差與近軸會聚點 R/(n−1)）」三種模式，可勾選顯示折射時的部分反射。題庫附 N15-HALFCYL-1。

N15（亦連到 N08 聲速）另有「海市蜃樓與聲道」實驗，處理折射率（或聲速）隨高度連續變化時的彎曲與「全反射」，四種模式：下現蜃景（炎熱路面）、上現蜃景（冷海面／晚上逆溫，含地球曲率，以修正折射率 n(1 + h/R) 換成平面問題）、晚上聲音傳得遠（可切換白天的聲影區）、深海聲道 SOFAR（Munk 聲速剖面）。光線與聲線以 RK4 積分 dθ/ds = cosθ·(dn/dy)/n（聲波用 n = c₀/c），左側（窄螢幕為下方）並列溫度與折射率（聲速）隨高度的分布圖，縱軸與場景對齊；光的兩種模式另有「眼睛看到的畫面（不放大）」，以逐層求解物體每一高度對應的視角畫出正立、倒立或多重的像。垂直方向依情境放大並標示倍數，比例尺不隨參數改變。深海聲道模式下方附海洋聲速、溫度、鹽度隨深度變化的參考圖（assets/images/real/sofar-sound-speed-profile.jpg，出處待補），以及鯨魚利用深海聲道長距離通訊、抹香鯨 236 分貝與水中分貝換算的說明。題庫附 N15-MIRAGE-1、N08-NIGHT-1。

N14 的視深實驗分為「拖曳眼睛：看魚也看鳥」「岸上看水中」「斜看池底」「水中看岸上」「水族箱：空氣—玻璃—水」「多層視深」六種模式。拖曳模式中眼睛可放在水面上或水面下，魚在水中游、鳥在空中飛，同時比較直射、折射成像與水面倒影（眼睛在水下且入射角大於臨界角時為全反射）。拖曳模式的像點由進入瞳孔上、下緣的折射光線反向延長求交點；水族箱則以對稱光束求像，不表示同一瞳孔的大小。動畫先顯示光的傳播，再沿出射方向反推到像。斜看模式畫出整片池底「看起來的位置」；水族箱模式提供家用魚缸（玻璃 1 cm）、大型水族館（壓克力 25 cm）與美ら海黑潮之海（壓克力 60 cm）三種實際情境，預設只顯示最後的虛像；進階設定可展開逐面成像。主圖與讀數使用同一組光束的實際交點，另外列出接近正視時的近軸近似 Σ 厚度／折射率。「多層視深」為純光線模擬：2–6 層，每層厚度與折射率可調；「視深」情境可看逐層中間像、大張角（到 89°，比例尺固定不隨角度縮放）時的像差與層間全反射，「全反射判斷」情境讓光由最上層入射，可勾選是否顯示各界面的判斷提示（預設隱藏），並可一鍵載入「1.7／1.5／1.3／1.6／1.4／1.0」類題。水族箱模式的光束張角可調到 70°，超過約 48.8° 時光在外壁全反射。拖曳模式可用勾選框只看魚或只看鳥。「評估練習：湖邊玩水」預設用一般人的估法出題：以生活物品描述看起來的深度（運動鞋、寶特瓶、椅子座面、課桌、流理台、直立式洗衣機、雙門冰箱），人站在岸邊幾乎正上方看腳前方的水；學生先算實際深度，再對照圖中人身上標的公分數判斷水會到哪裡。物品放在岸上當比例尺，水中以量尺對照「看起來 1 個物品高」與「實際 4/3 個」。也可切換成用公分數字作答。「🎲 重新出題」不需重新載入頁面；題庫另有四題同情境的固定題（N14-LAKE-1～4）。

水族箱的水、窗材與空氣光路以不同顏色標示，角度卡片對照兩次偏折；可展開局部光路，折角保持真實比例。窗厚、材質、張角與中間像收在進階設定。`audit_aquarium.js` 核對 480 組 Snell 定律、全反射、光線交點與近軸極限；視覺健檢另涵蓋薄窗、逐面成像、接近臨界角與全反射。

```bash
python scripts/audit_codebase.py
node scripts/audit_learning_content.js
node scripts/audit_page_recovery.js
node scripts/audit_swing_work.js
node scripts/audit_aquarium.js
```

靜態健檢驗證題號、資源、DPR 繪圖原則；導讀健檢驗證每節資料、先備圖、答案鍵與前端語法。

頁面復原健檢以實際 HTML／JS 做故障注入，涵蓋必要腳本缺檔、語法錯誤與渲染例外；復原入口另需瀏覽器操作核對。

另開啟 `wave_optics_review.html?selftest=1`，掃描所有實驗模式的 **實際 360 / 560 / 900px 畫布**。文字碰撞逐幀比較，檢查左右上下四邊及執行期錯誤；跨幀不同文字不視為同時重疊。此健檢不涵蓋獨立水波頁，也不取代手機畫面、參數邊界與實際操作的視覺核對。

專案 UI 守則見 `.agents/rules/ui_canvas_verification.md`。測試截圖與臨時檔放在 `scratch/`。
